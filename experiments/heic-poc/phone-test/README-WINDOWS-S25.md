# YardVision S25 HEIC integration test — LOCAL ONLY

This ZIP contains **the actual development-branch YardVision browser photo-preparation
scripts** plus a bundled HEIC decoder. It is **not the live site**. The photo
never leaves your phone: nothing is sent to the test server except GET requests
for the static app assets. This package does not include accounts, Stripe,
AI generation, cookies or customer records.

## Run on Windows + Galaxy S25

1. Download the GitHub Actions artifact \`yardvision-s25-heic-local-test\` and
   extract the ZIP to a folder on your Windows PC. Do not upload the folder
   to a hosting provider or to Render.
2. Double-click \`START-YARDVISION-TEST.bat\`. Keep that window open.
3. On the Windows screen, find a printed \`http://192.168.x.x:8765\` or
   \`http://10.x.x.x:8765\` address.
4. Make sure your Galaxy S25 and PC use the **same trusted home Wi-Fi**.
   Open that exact address in Chrome on the S25. Do **not** use
   \`http://localhost:8765\` from the phone—it points to the phone, not PC.
5. Choose your genuine camera HEIC photo (ideally the same non-sensitive one
   used for the earlier test). The page shows **PASS** with a preview if
   it converted successfully. Check the preview orientation and proportions.
6. Optionally tap **Save processed photo**, then open the saved JPEG in Gallery.
   You can also select ordinary JPG/PNG photos as regressions.
7. Stop the server by closing the Command Prompt window or pressing Ctrl+C.

**Troubleshooting:** If your S25 cannot reach the address, check Windows
Firewall. If prompted, allow Node.js only on **Private networks**, never Public.
Turn off VPNs or mobile-data isolation if they prevent local Wi-Fi access.
Do not configure router port forwarding or expose this test over the internet.

## Safety / acceptance limitations

- **Important local-only security exception:** this prototype allows JavaScript `unsafe-eval` **only on the decoding worker script's CSP response**, because the proven `heic-to/next` build needs it. The main test page has no such permission. **This is NOT production CSP acceptance and must not be copied to Render/YardVision**. A production-grade CSP-safe decoder remains a release blocker.
- The decoder is a library-based proof of concept. Nested worker cleanup,
  compressed-pixel memory bounds, and mobile browser resource limits have not
  been fully independently verified. If the phone gets hot or Chrome becomes
  unresponsive, close the tab. Test one ordinary non-sensitive photo at a time.
- **Passing this local test is not approval for production.** Real hosted
  security checks, dependency licensing/notice obligations, actual backend
  upload and generation, account/billing regressions, and explicit release
  approval remain outstanding.
- Node/this package makes **no outgoing requests**. The page and decoder
  run locally. The included sample HEIC is a small public image fixture.
- Dependency source: \`heic-to@1.6.7\`, licensed LGPL-3.0. See
  https://github.com/hoppergee/heic-to for source, notices and licensing.
  Additional codec and transitive notices must be evaluated before commercial
  distribution. This ZIP is for private evaluation, not a customer release.

The bundle is generated by GitHub Actions from the \`experiment/heic-decoder-20261102\`
branch. Confirm the CI run completed successfully before testing.
